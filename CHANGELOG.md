# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-06
### Added
- Initial project scaffolding for the Call Core Platform.
- Monorepo setup with `apps` and `packages` workspace configuration.
- Shared `call-core` SDK package boilerplate with LiveKit dependencies.
- Node.js API backend (`apps/api`) setup with Hono framework.
- Processing Worker (`apps/worker`) setup with BullMQ, OpenAI, and FFmpeg dependencies.
- Frontend React Web App (`apps/web`) initialized using Vite.
- Frontend React Native Mobile App (`apps/mobile`) initialized using Expo.
- Base markdown documentation and checklists established for project phases.
- Author: Sumit Srivastava
